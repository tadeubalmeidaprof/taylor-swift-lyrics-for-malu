# Taylor Swift Lyrics for Malu

Jogo web de palavras criado como presente para Malu.

## Direção do projeto

- Introdução cinematográfica e leve com identidade própria.
- Tela do jogo branca, limpa e responsiva.
- Músicas aleatórias vindas do Supabase.
- Letras ficam ocultas e são reveladas conforme as palavras corretas são digitadas.
- Contador de progresso e cronômetro controlado pelo backend.
- Refrões podem receber destaque visual sutil, sem texto ou dica explícita.
- Sem microfone e sem tentativa de adivinhar o nome da música.

## Stack

- React
- TypeScript
- Vite
- Supabase
- CSS moderno sem biblioteca pesada de animação
